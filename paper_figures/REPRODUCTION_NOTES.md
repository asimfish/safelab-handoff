# Portable reproduction of the final paper panel

The supplied README.md, compute_table2.py, plot_srk.py, compute_table2_v12best.py, plot_two.py and plot_len.py are retained verbatim. The latest author-supplied plot_two.py and plot_len.py use paths relative to their own directory.

From this directory, with matplotlib installed:

    python3 reproduce.py

For data and table verification without plotting dependencies:

    python3 reproduce.py --no-plots

The directory includes the exact 749-evaluation snapshot as tracked `data.json`. The entry verifies its byte count and SHA256 from INPUT_MANIFEST.json, then executes the calculation scripts. Both compute scripts also run directly from this directory without downloading inputs. It verifies BOTH the three-setting main Avg and the four-setting full-table Avg against frozen-data.json. It also produces the legacy strict-reference curves and CSV.

`portable_plot_two.py` executes the unchanged supplied plot_two.py and plot_len.py sources with only its process-local D assignment relocated to an owned temporary directory. It uses the frozen final two-method arrays, writes the final 3/7, all-length, task-10 and success-vs-length PDF/PNG files into out/, and never writes the source author's /tmp path. Original source bytes are preserved.

The snapshot is 5,898,454 bytes (SHA256 b5d444842545051dddca696d4a8c87c5c0984547c8f29785443fbe8df91ccd99). It is committed as `paper_figures/data.json` as explicitly requested. INPUT_MANIFEST.json also records an anonymous TOS backup of identical bytes. The root dashboard `data.json` is unchanged.

Direct reproduction (matplotlib required only for plotting):

    cd paper_figures
    python3 compute_table2_v12best.py
    python3 compute_table2.py extra
    python3 plot_srk.py
    python3 plot_two.py
    python3 plot_len.py

The portable entry additionally checks the frozen tables and uses the rounded, author-supplied final arrays for the two-method publication plots. Direct plot_two.py reads the full-precision strict arrays generated by compute_table2.py.


The main table is v1.2-relaxed / best of h4,h8; final progress figures are v1.1 / mean horizons. out/srk.csv and safelab_srk_curves.pdf are historical strict-reference outputs containing the subsequently supplied π0.5 phase distributions. π0.5 3-subtask SR@3 can exceed episode success (3.5 vs. 2.0) because final hold/safety conditions can fail. Only MemoryVLA task 7 lacks an evaluated curve.
